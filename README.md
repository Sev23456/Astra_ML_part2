# Состав папки отчёта

Эта папка собрана для ручной проверки работы без поиска файлов по проекту.
Начните с `REPORT.md`.

| Папка или файл | Содержимое |
|---|---|
| `REPORT.md` | Подробный отчёт: методика, результаты, ограничения и порядок проверки. |
| `summary.json` | Главный итог нового расчёта: выбранная модель, test AUC, порог, S, B и ZA. |
| `frozen_selection_before_test.json` | Решения, сохранённые до тестовой выборки: признаки, seed, параметры и пороги. |
| `tables/` | Все компактные CSV-таблицы нового расчёта: метрики, выходы, бины гистограмм, поиск параметров и контроль Train/Test. |
| `figures/` | Восемь PNG-графиков: входные признаки, ROC, кривые обучения, пороги и отклик моделей. |
| `comparison/` | Сверка нового и исходного расчётов: 198 из 198 проверок пройдены. |
| `root_parquet_audit_original/` | Завершённый исходный ROOT/Parquet-аудит для 11 MC-процессов. |
| `scripts/zgamma_analysis.py` | Основной скрипт: полный анализ, обучение, таблицы и результаты. |
| `scripts/zgamma_plots.py` | Код построения всех графиков из `figures/`. |
| `RUN_SIMPLE.txt` | Команды полного повторного запуска. |

В набор сознательно не включены большие бинарные файлы, Parquet с
предсказаниями, крупные Parquet-таблицы ROC/сканов и вспомогательные
проверочные скрипты. Они остаются в исходной папке проекта и в
`results_simple/`. Основной скрипт анализа и скрипт графиков добавлены сюда.
Все компактные таблицы, на которые ссылается отчёт, и все изображения также
добавлены сюда.

Свежий ROOT/Parquet-аудит из `audit_root_parquet.py` пока не завершён;
в папке `root_parquet_audit_original/` лежит завершённый исходный аудит.
